### 3. 記憶體管理

#### `kalloc.c`：物理內存分配

`kalloc.c` 是 xv6 內核中管理物理內存分配的核心模塊。它提供了一個簡單的內存分配器，用於管理固定大小的內存塊（頁），這些頁的大小通常為 4096 字節（4 KB）。這種分配器負責為用戶進程、內核棧、頁表等分配和釋放物理內存頁。

`kalloc.c` 的主要功能包括初始化內存分配器、分配內存頁、釋放內存頁，以及維護一個空閒頁的鏈表。

#### 1. 結構設計

- **`struct run`**: 每個空閒頁都由一個 `run` 結構表示，`run` 結構中的 `next` 指針用於鏈接下一個空閒頁。
  
  ```c
  struct run {
      struct run *next;
  };
  ```

- **`kmem`**: 用於管理空閒頁鏈表的全局變量，包含一個自旋鎖和空閒頁的鏈表頭。
  
  ```c
  struct {
      struct spinlock lock;
      struct run *freelist;
  } kmem;
  ```

#### 2. 內存初始化

- **`kinit` 函數**: 該函數初始化內存分配器，設置空閒頁的鏈表。它調用 `freerange` 來將內存範圍內的每個頁加入到空閒鏈表中。
  
  ```c
  void kinit() {
      initlock(&kmem.lock, "kmem");
      freerange(end, (void*)PHYSTOP);
  }
  ```

- **`freerange` 函數**: 將指定範圍內的每個頁都標記為空閒，並調用 `kfree` 將這些頁加入到空閒頁的鏈表中。
  
  ```c
  void freerange(void *pa_start, void *pa_end) {
      char *p;
      p = (char*)PGROUNDUP((uint64)pa_start);
      for(; p + PGSIZE <= (char*)pa_end; p += PGSIZE)
          kfree(p);
  }
  ```

#### 3. 內存分配和釋放

- **`kalloc` 函數**: 分配一個 4096 字節的頁。如果鏈表中有空閒頁，則從鏈表中取出一個頁，並將其從鏈表中移除。否則返回 `0` 表示無法分配內存。
  
  ```c
  void *kalloc() {
      struct run *r;
      acquire(&kmem.lock);
      r = kmem.freelist;
      if(r)
          kmem.freelist = r->next;
      release(&kmem.lock);
      if(r)
          memset((char*)r, 5, PGSIZE); // 填充數據以捕獲錯誤
      return (void*)r;
  }
  ```

- **`kfree` 函數**: 釋放一個頁，將其重新加入到空閒頁的鏈表中。在加入鏈表之前，對頁進行基本的檢查，確保它是有效的內存頁。
  
  ```c
  void kfree(void *pa) {
      struct run *r;
      if(((uint64)pa % PGSIZE) != 0 || (char*)pa < end || (uint64)pa >= PHYSTOP)
          panic("kfree");
      memset(pa, 1, PGSIZE);  // 填充數據以捕獲錯誤
      r = (struct run*)pa;
      acquire(&kmem.lock);
      r->next = kmem.freelist;
      kmem.freelist = r;
      release(&kmem.lock);
  }
  ```

#### 4. 小結

`kalloc.c` 中的物理內存分配器通過簡單的空閒頁鏈表管理物理內存，實現了內存的分配與釋放。這種設計雖然簡單，但非常有效，適合 xv6 這樣的教學操作系統。它為用戶進程、頁表和內核數據結構提供了基本的內存管理服務。
